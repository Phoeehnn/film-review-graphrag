# 使用指南

先在智能问答页输入问题，也可以点击示例问题。统计结果只代表本项目样本。

## 直接问答和Agent怎么选

直接问答适合目标清楚的一次查询，例如查看某部电影的评论量、寻找表达相近观点的评论。自动模式会按规则选择图谱、向量或融合；研究时可强制指定路径。

Agent适合需要分几步查证的问题。它会选择已有工具并展示调用记录；工具选对也不保证最终答案正确，仍应核对证据。

## 筛选与追问

电影、主题、情感、日期、星级等筛选会影响实际候选范围。主题描述评论聚类，不是电影题材。启用短期会话后可追问或固定条件；更改对象时检查条件栏，撤销不用的条件。

## 回答依据

统计以数据库聚合行、分母和查询为准；评论以引用原文和元数据为准。不要把评论中表达的愤怒等同于作者不喜欢电影，也不要把预测情绪标签当人工真值。

## 研究复核页

复核工具代码随仓库提供，但实际运行回答与评分文件不提供。没有完整数据时会显示暂无数据。不能把空表、执行成功或AI建议分当成人工最终准确率。
