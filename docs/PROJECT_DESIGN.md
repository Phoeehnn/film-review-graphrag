# 项目设计

研究底座把评论、电影、主题、星级倾向和预测情绪连接成图谱，并复用384维多语言SBERT向量。服务层按问题特点选择结构化统计、语义评论或二者组合。

数量、比例与排名依赖完整样本计算，不能用少量相似评论估计。语义检索补充同义表达，适合寻找评论本身能支持的观点。融合只对评论候选做RRF，统计行独立保留。

Agent通过六个经过参数校验的工具完成分步查询。会话层把固定条件、历史摘要和证据映射分别维护，摘要不能改变固定筛选。接口与界面分离，通过FastAPI/SSE连接。

1.4.2修复别名先匹配后跳过另一个片名简称的问题：继续检查未匹配的唯一前缀，并遮蔽已匹配片名；显式筛选仍优先。
