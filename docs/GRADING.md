# 评分规则

答案评分：Y表示核心任务完成且有依据；P表示完成了有用子任务但缺少重要部分；N表示核心未完成、关键错误或无有效答案。P不表示“不确定”，语言不够漂亮也不自动降分。

任务完成与拒答合理性分开记录。例如要求全库统计而vector仅返回少量评论，诚实拒答可以是答案N、拒答正确Y。只有题目本身预设不可回答时，正确拒答才可能答案Y。

检索相关性：2表示全部语义要点及硬筛选满足；1表示部分相关；0表示无关、反向或违反筛选。合成例子：找“步调缓慢但构图精致”，只称赞构图不能得2分。

AI建议与人工确认应保留来源。公开聚合成绩的混合评分方法见RESULTS.md；本仓库不提供正式逐题分数。
