# 离线测试与复现边界

安装requirements-dev后运行`python -m pytest tests -q`。测试禁止外部TCP连接；允许本机事件循环需要的回环连接。模型Hub开启离线模式；不需要实际API密钥，不执行付费问答。

测试中的图谱节点、评论、用户ID和证据是合成fixture，不是公开的原始用户记录。数据专用的AI复核输入和UI最终确认检查在没有私有文件时明确跳过；不要把跳过数隐藏或称为原私有完整测试全部通过。

核心覆盖只读安全、LIMIT、范围、规则路由、RRF、工具预算、会话、SSE、超时和多电影组合。公开副本额外通过配置/空页面检查的情况见发布检查单。

本机从新Git仓库克隆后运行测试，只证明该副本的代码依赖较完整，不等于另一台电脑的服务部署验证。没有私有数据时，未做公开副本的全量数据初始化或真实生成验证。

真实评测脚本需要数据、明确版本及模型费用授权；单元测试替身不能计入效果成绩。
