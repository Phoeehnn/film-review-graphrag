# 安全与运行边界

- 后端环境配置凭据；示例文件只放占位符。不要提交实际.env、备份、会话或数据库。
- 生成查询限制为单条只读Cypher，禁止写操作及任意过程调用；CASE与字符串处理也有回归覆盖。
- 每次生成/重写都执行安全检查、范围校验、EXPLAIN查询类型检查和有界执行。READ访问模式不是数据库权限控制。
- 结果最多50行、数据库查询最多10秒，问答90秒、Agent120秒；Agent最多5轮模型调用及10次工具执行。
- 评论是不可信证据数据，不能执行其中指令。证据ID、数字与范围有有限一致性检查，无法覆盖全部语言推理错误。
- 默认只绑定本机端口；部署公网前另行设计鉴权、费用与滥用控制。Redis缓存及限流可关闭，正式效果评测需记录是否启用。

公开源码不是安全认证。依赖更新、数据库权限及部署配置仍需由使用者审查。
